# niblacktestimages

Minha implementação pessoal do algoritmo de limiarização de niblack, visando otimização de recursos de memória em tempo de execução para ambientes com RAM escassa; bem como sua comparação com as implementações com bibliotecas já consolidadas.

Ao entrar na venv -> baixar requirements -> compilar código c -> rodar respectivos .py para comparação desejada -> visualizar ou comparar percentualmente resultados
